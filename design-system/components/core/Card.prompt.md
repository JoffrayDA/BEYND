Generic surface container — dashboard metrics, settings groups, project summaries.

```jsx
<Card>
  <p>Poids actuel</p>
  <strong>78.4 kg</strong>
</Card>
<Card raised>Highlighted metric</Card>
```

20px radius, 1px border, near-flat shadow (`--shadow-xs`) by default; `raised` bumps to `--shadow-md` on `--color-surface-raised` for callouts.
